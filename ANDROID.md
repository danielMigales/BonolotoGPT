# BonolotoGPT para Android

El proyecto Android se genera con Capacitor a partir de la web existente.

## Crear el APK

1. Abre la pestaña **Actions** del repositorio.
2. Selecciona **Crear APK Android de BonolotoGPT**.
3. Pulsa **Run workflow**.
4. Cuando termine correctamente, descarga el artefacto **BonolotoGPT-Android**.
5. Extrae el ZIP e instala `app-debug.apk` en Android. Si Android lo solicita, autoriza temporalmente la instalación desde esa fuente.

## Actualizaciones

La aplicación abre la versión publicada en GitHub Pages: https://danielmigales.github.io/BonolotoGPT/. Por tanto, los cambios publicados en la web estarán disponibles al volver a abrir la app, sin recompilar el APK.

## Alcance de esta compilación

El APK de depuración es instalable para pruebas y distribución directa. No es todavía una versión firmada para Google Play. La aplicación necesita conexión a Internet para cargar la web y sus datos; no ofrece funcionamiento sin conexión.
